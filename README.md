# E-Commerce Sales & Customer Analytics

## 📌 Project Overview

An Excel-based data analytics project focused on analysing e-commerce sales performance, profitability, customer behaviour, and order trends through PivotTables, KPIs, and an interactive dashboard.

## 🎯 Objectives

* Analyse sales and profit performance across categories and states.
* Identify top-performing and low-performing products.
* Understand customer purchasing patterns and order status distribution.
* Track monthly sales and profit trends.

## 🛠️ Tools Used

* Microsoft Excel
* PivotTables and PivotCharts
* Excel formulas and calculated columns
* KPI dashboard and data visualization

## 📊 Key Performance Indicators

* Total Sales
* Total Profit
* Total Orders
* Total Customers
* Units Sold

## 📈 Analysis Performed

* Category-wise sales and profit analysis
* Monthly sales and profit trends
* State-wise sales comparison
* Top 10 and bottom 10 product analysis
* Customer and payment-method analysis
* Order status and age-group analysis

## 📁 Project Files

* Excel workbook containing the analysis and dashboard
* PDF export of the dashboard

## 💡 Key Learnings

This project provided practical experience in data cleaning, calculated columns, PivotTables, chart creation, KPI development, and dashboard design using Microsoft Excel.
